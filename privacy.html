Privacy Policy — Brett Adams Workspace Integration

Last updated: 2026-07-26

Overview

Brett Adams Workspace Integration is a personal software project built and operated solely by Brett Adams for his own individual use. It is not a publicly distributed product, and no other individuals use it or have access to it.

What it does

It connects Brett's own Google account to a personal AI coding assistant (Claude Code) running locally on his own computer, using Google's official OAuth 2.0 authorization flow. Through this connection it can, on Brett's own behalf and at his direction:

  • Send and compose Gmail messages and drafts
  • Create files in Google Drive
  • Create, read, update, and delete Google Calendar events
  • Read and write Google Sheets data

Data storage

OAuth tokens are stored locally on Brett's own personal computer, protected by the operating system's own user-account file permissions. They are never transmitted to any third-party server.

Data sharing

No data accessed through this integration is sold, shared, or disclosed to any third party. All data flows directly between Brett's own Google account and his own local machine.

Data retention and revocation

Access can be revoked at any time via Google Account security settings (myaccount.google.com/permissions). Locally stored tokens are deleted when the integration is removed from the machine.
